FinSight V8.6 完整包（包含 V8.4 / V8.5 的全部修复）

本版新增
1. 按 20 家不同行业公司（航空、零售、科技、能源、工业、医药、消费、房地产开发、公用事业、银行）的 10-K 写法补全取数：
   - 标准 SEC 标签：存货、应收、短期投资、PP&E、CapEx、利息、税、预付、应计工资、递延收入、短期借款等都增加了备选标签
   - 存货分项相加：产成品/在制品/原材料、天然气/煤/物料、毛额−LIFO
   - 10-K 原文兜底：行名先清洗（去掉 less allowance、net of、括号、破折号），再按资产负债表"流动/非流动"分区识别，同名行不再互相冲突
2. 清理压缩包：删除旧版说明、旧 service worker、已经内嵌在 index.html 里的重复文件。

部署
- 全部上传到 GitHub 根目录并提交，等 Netlify Published，页面和后端都应显示 8.6。
- GitHub 上传不会自动删除旧文件；旧文件留着不影响运行，想要干净可以在 GitHub 里手动删除（列表见 README.md）。

限制
- 10-K 原文兜底只读所选年份那一份 10-K，所以补的是当年和上一年。
- 银行、保险没有存货、CapEx 等，这些格子保持空白属于正常。
- 测试用的是转录或模拟数据，没有连线上 SEC。
