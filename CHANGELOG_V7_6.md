# V7.6 issuer-linked accounting cases

Accounting Cases now shows the Overview issuer and relevant reported source accounts with tags and fiscal dates. Fixed dollar amounts are replaced with a user-entered hypothetical amount in USD millions and a coverage/service period. Plain-language stages explain the timing, with a debit/credit glossary and issuer-specific investigation prompts. None of these hypothetical transactions is claimed to come from the issuer's filings.

Stage buttons apply the hypothetical event directly to the issuer-linked Three-Statement Explorer without clearing existing transactions. Later-stage settlement requires sufficient verified or simulated balances. The Explorer displays baseline, change and simulated value. Changing the issuer clears the case amount and transaction simulation.

Unsupported source lines remain unavailable. No amount is inferred from an unrelated account. Deploy all assets and the SEC function from this complete package; it has not been published automatically. Browser layout and live SEC connectivity have not been verified.
