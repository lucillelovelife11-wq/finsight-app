# V7.2 visible calculation feedback

Analysis messages identify the loaded ticker and fiscal year rather than using an unnamed company. Calculate buttons now show feedback directly below the button. Missing inputs are listed by name, outlined in red and marked invalid for assistive technology. An explicit click focuses the first missing input. Missing data still cannot be silently replaced by zero. Complete inputs produce an updated-result notice; changed inputs clear stale results.

Deploy the complete archive and reload to activate the new service-worker cache. This package has not been published to the live site.
